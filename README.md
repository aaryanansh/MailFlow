# MailFlow

MailFlow is a Python-based Gmail automation application that helps users manage and automate email-related tasks through a simple web interface.

## Features

- Gmail integration using Google OAuth 2.0
- Send emails through Gmail
- Manage email-related automation
- Upload files for email processing
- Web-based interface
- Secure OAuth credential handling
- Python-based backend

## Technologies Used

- Python
- Flask
- Gmail API
- Google OAuth 2.0
- HTML
- CSS
- JavaScript
